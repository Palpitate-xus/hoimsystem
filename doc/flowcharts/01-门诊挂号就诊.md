# 门诊挂号就诊业务流程图

> 数据来源：`app/routers/patient.py`、`checkin.py`、`charge.py`、`queue.py`、`doctor.py`（2026-08 代码实况）

## 1. 预约挂号全流程（患者端）

```mermaid
flowchart TD
    A[患者登录] --> B[选择科室/医生/日期]
    B --> C[查询排班 slotPool<br/>GET /doctorScheduleManagement]
    C --> D{号源 number > 0?}
    D -- 否 --> E[提示: 该时段号源已满] --> C
    D -- 是 --> F{30天内违约≥3次?}
    F -- 是 --> G[❌ 拒绝预约<br/>预约资格暂停30天]
    F -- 否 --> H{同医生同日期<br/>已有待就诊预约?}
    H -- 是 --> I[❌ 拒绝: 不能重复预约]
    H -- 否 --> J[原子扣减号源<br/>UPDATE number=number-1<br/>WHERE number>0]
    J --> K{更新行数=1?}
    K -- 否 --> E
    K -- 是 --> L[创建 Appointment<br/>status=0 待就诊]
    L --> M[✅ 预约成功]
```

**关键校验**（代码位置）：
- 违约拦截：`patient.py:152-162`（BreachRecord 30天窗口计数）
- 挂号费：挂号成功自动产生 `Charge(charge_type="registration")`，普通/专家标准由 config 表配置（`registration_fee_common`/`registration_fee_specialist`）
- 违约扫描：`scheduler.py` breach_scan 每日任务——前一日未报到且未取消的预约记违约、置取消、回补号源（幂等）
- 排班匹配：`patient.py:163-168`（doctor/specialist/department 与 schedule 一致）
- 重复预约：`patient.py:175-182`
- 号源原子扣减：`patient.py:183-186`（条件 UPDATE 防并发超卖）

## 2. 预约取消

```mermaid
flowchart TD
    A[患者发起取消] --> B{预约存在?}
    B -- 否 --> C[❌ 预约记录不存在]
    B -- 是 --> D{status==2 已取消?}
    D -- 是 --> E[❌ 无需重复操作]
    D -- 否 --> F{status==0 待就诊?}
    F -- 否 --> G[❌ 已报到/已就诊不能取消]
    F -- 是 --> H{操作者是本人或家属?}
    H -- 否 --> I[❌ 403 无权取消他人预约]
    H -- 是 --> J[原子置 status=2<br/>条件 UPDATE WHERE status=0]
    J --> K[号源回加 number+1]
    K --> L[✅ 取消成功]
```

## 3. 自助报到（kiosk 双因子）

```mermaid
flowchart TD
    A[自助机输入] --> B[身份证号 + 手机号后4位]
    B --> C[GET /checkIn/getAppointments]
    C --> D{双因子匹配 Patient?}
    D -- 否 --> E[❌ 身份证号与预留手机号不匹配]
    D -- 是 --> F[返回当日 status=0 的预约列表]
    F --> G[患者选择预约]
    G --> H[POST /checkIn/checkIn<br/>uuid + identity + phone_tail]
    H --> I{预约存在且当天?}
    I -- 否 --> J[❌ 只能在预约当天报到]
    I -- 是 --> K{status==0?}
    K -- 否 --> L[❌ 已报到/已就诊/已取消]
    K -- 是 --> M{is_breach?<br/>当天23:59后}
    M -- 是 --> N[记录违约 BreachRecord<br/>超时未报到<br/>（兜底：主力为 scheduler<br/>breach_scan 每日任务）]
    M -- 否 --> O[取当日最大 queue_number+1]
    N --> O
    O --> P[创建 Queue 记录 status=0]
    P --> Q[Appointment.status=1 已报到]
    Q --> R[✅ 返回排队号]
```

**防身份探测**：双因子（身份证+手机尾号）为 2026-08 安全加固，仅凭身份证号无法枚举他人预约。

## 4. 窗口挂号（收费员/挂号员代办）

```mermaid
flowchart TD
    A[收费员刷身份证] --> B[GET /windowRegistration/patient]
    B --> C{患者档案存在?}
    C -- 否 --> D[❌ 病人信息不存在 请先注册]
    C -- 是 --> E[选择排班时段]
    E --> F{该患者已有同医生<br/>有效挂号 status=0?}
    F -- 是 --> G[❌ 重复挂号]
    F -- 否 --> H{号源 number>0?}
    H -- 否 --> I[❌ 号源已满]
    H -- 是 --> J[原子扣号<br/>UPDATE WHERE number>0]
    J --> K{更新行数=1?}
    K -- 否 --> I
    K -- 是 --> L[创建 Registration<br/>allocate_registration_id<br/>status=0]
    L --> M[✅ 返回挂号凭证]
```

**窗口退号**：`Registration.status 0→3`，号源回加 +1（`charge.py:440-468`）。已就诊（status≠0）不可退。

## 5. 分诊叫号

```mermaid
flowchart TD
    A[报到完成 Queue status=0] --> B{分诊台 triageDesk/create}
    B --> C[导诊/护理录入生命体征<br/>与分诊级别 1-4]
    C --> D[护士预检 vitalSign/create]
    D --> E[叫号 queue/callNext]
    E --> F[Queue.status=1 已叫号]
    F --> G[患者进入诊室]
    G --> H{过号?}
    H -- 是 --> I[queue/pass 顺延一位]
    H -- 紧急 --> J[queue/emergency 优先插队]
    I --> E
    J --> E
    H -- 否 --> K[医生接诊]
```

## 6. 门诊收费与退费

```mermaid
flowchart TD
    A[医生开处方/检查] --> B[生成 Charge status=0 待缴费]
    B --> C{缴费方式}
    C -- 窗口 --> D[POST /chargeManagement/charge]
    C -- 线上支付 --> E[POST /payment/create]
    E --> F[支付回调 status=1]
    D --> G{原子置 status=1<br/>WHERE status=0}
    G -- 行数≠1 --> H[❌ 重复收费拦截]
    G -- 行数=1 --> I[✅ 缴费成功<br/>现金同事务补写 Payment<br/>channel=cash status=1]
    F --> I
    I --> J{需要发票?}
    J -- 是 --> K[invoice/create 开具发票]
    J -- 否 --> L[日结对账<br/>dailySettlement/report]
    K --> L
    I --> M{退费?}
    M -- 是 --> N{status==1 已缴费?}
    N -- 否 --> O[❌ 未缴费或已退费]
    N -- 是 --> P[原子置 status=2<br/>WHERE status=1]
    P -- 行数≠1 --> O
    P -- 行数=1 --> Q[关联 Payment 置 status=3 退款中]
    Q --> Q2[关联发票作废<br/>Invoice.status=2<br/>PDF 下载拦截]
    Q2 --> R[✅ 全额退款]
```

**并发安全**：缴费/退费均用条件 UPDATE + rowcount 校验，两个并发请求只有一个成功（`charge.py:98-146`）。**账目一致**：现金收费补写支付流水（收费域=支付域）；退费联动作废发票，作废票据不可再下载报销。

## 7. 违约管理

```mermaid
flowchart TD
    A[预约日 23:59 后未报到] --> B[下次任何报到操作时<br/>is_breach 检测]
    B --> C[record_breach 记录违约]
    C --> D[违约计数 +1]
    D --> E{30天内累计≥3次?}
    E -- 是 --> F[预约资格暂停30天<br/>appointmentManagement/create 拦截]
    E -- 否 --> G[正常预约]
    F --> H[30天后自动恢复]
```
