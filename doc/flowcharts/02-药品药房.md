# 药品与药房业务流程图

> 数据来源：`app/routers/doctor.py`（处方开立）、`pharmacy.py`（审方/发药/退药）、`purchase.py`、`drug_damage.py`、`antibiotic.py`、`special_drug.py`、`skin_test.py`（2026-08 代码实况）

## 1. 处方开立（医生工作站）

```mermaid
flowchart TD
    A[医生选择患者] --> B[选药品 + 数量]
    B --> C{含限制级/特殊级<br/>抗菌药? antibiotic_level>=2}
    C -- 是 --> D{医生是 admin/director?}
    D -- 否 --> E{有匹配的<br/>已通过审批单?}
    E -- 否 --> F[❌ 需先提交抗菌药审批]
    E -- 是 --> G[审批单绑定处方]
    D -- 是 --> H[继续]
    C -- 否 --> H
    H --> I{过敏史冲突?<br/>药品名 vs 过敏关键词}
    I -- 是 --> J[❌ 拒绝: 过敏史冲突]
    I -- 否 --> K{配伍禁忌组合?}
    K -- 是 --> L[❌ 拒绝: 配伍禁忌]
    K -- 否 --> M[逐项原子扣库存<br/>UPDATE stock=stock-n<br/>WHERE stock>=n AND status=0]
    M --> N{全部扣减成功?}
    N -- 否 --> O[rollback ❌ 库存不足]
    N -- 是 --> P[创建 Prescription status=0<br/>+ PrePha 明细]
    P --> Q[生成 Charge status=0<br/>金额=Σ 单价×数量]
    Q --> R[✅ 处方开立成功]
```

**关键校验**：
- 抗菌药审批：`doctor.py:349-379`（审批单需 patient/applicant/drug 三匹配且未绑定处方）
- 过敏匹配：`doctor.py:381-410`（词边界精确匹配，避免 partial match 误判）
- 库存原子扣减：`doctor.py:436-448`（条件 UPDATE 防负库存/并发双扣）

## 2. 药房审方与发药

```mermaid
flowchart TD
    A[处方 status=0 待审核] --> B[药师审方<br/>POST /pharmacy/audit]
    B --> C{status==0?}
    C -- 否 --> D[❌ 处方状态不正确]
    C -- 是 --> E[原子置 status=1<br/>WHERE status=0]
    E -- 行数≠1 --> D
    E -- 行数=1 --> F[已审核 待发药]
    F --> G[发药 POST /pharmacy/dispense]
    G --> H{status==1?}
    H -- 否 --> I[❌ 未审核或已发药]
    H -- 是 --> J{有过期批次药品?<br/>expireddate < today}
    J -- 是 --> K[❌ 禁止发药: 药品已过期]
    J -- 否 --> J2{该患者对该药<br/>有皮试医嘱?}
    J2 -- 阳性 status=3 --> K2[❌ 皮试阳性禁止发药]
    J2 -- 未完成 0/1 --> K3[❌ 皮试未完成禁止发药]
    J2 -- 阴性/无医嘱 --> J3{抗菌药<br/>antibiotic_level≥2?}
    J3 -- 是且无已批准审批单 --> K4[❌ 无有效抗菌药审批禁止发药]
    J3 -- 否/已批准 --> L[批次 FEFO 扣库存+出库台账<br/>总量库存原子扣减]
    L -- 库存不足 --> K5[❌ 整单拒绝回滚]
    L -- 足够 --> L2[原子置 status=2<br/>WHERE status=1]
    L2 -- 行数≠1 --> I
    L2 -- 行数=1 --> M[生成 DispenseVerification<br/>status=0 待护士核对]
    M --> N[护士核对 POST /pharmacy/verify]
    N --> O[DispenseVerification.status=1<br/>已核对 / 2=异常]
    O --> P[✅ 发药闭环完成]
```

> **FEFO 出库**：发药按"先过期先出"从批次扣减并写 `PharmaceuticalStockLedger`（outbound）；未启用批次管理的药品跳过批次账（总量库存开方时已预留扣减）。退药走 `_return_to_batches` 回冲批次并写 return 台账。

## 3. 退药回冲

```mermaid
flowchart TD
    A[发起退药] --> B{处方 status==2 已发药?}
    B -- 否 --> C[❌ 未发药或已退药]
    B -- 是 --> D{退药数量 > 0?}
    D -- 否 --> E[❌ 数量必须大于0]
    D -- 是 --> F[原子扣减 PrePha.number<br/>WHERE number >= 退药数]
    F -- 行数≠1 --> G[❌ 超过处方数量]
    F -- 行数=1 --> H[库存回加 stock += n]
    H --> I{明细全部退完?}
    I -- 是 --> J[处方 status=4 全退]
    I -- 否 --> K[保持 status=2<br/>可继续部分退]
    J --> L[✅ 退药成功]
    K --> L
```

**并发安全**：退药数量校验并入 UPDATE 条件，并发退药不会超退（`pharmacy.py:228-239`）。

## 4. 抗菌药分级审批

```mermaid
flowchart TD
    A[医生开限制级抗菌药] --> B[提交审批申请<br/>POST /antibiotic/apply]
    B --> C[AntibioticApproval<br/>status=0 待审批]
    C --> D[主任/管理员审批]
    D --> E{批准?}
    E -- 否 --> F[status=2 驳回<br/>医生修改或放弃]
    E -- 是 --> G[status=1 已批准<br/>prescription_id=NULL]
    G --> H[医生开处方携带审批单ID]
    H --> I{审批单四要素匹配?<br/>患者+申请人+药品+未绑定}
    I -- 否 --> J[❌ 拒绝开方]
    I -- 是 --> K[审批单绑定 prescription_id]
    K --> L[✅ 处方继续后续校验]
```

## 5. 采购入库与库存台账

```mermaid
flowchart TD
    A[药房提交采购申请<br/>POST /purchase/create] --> B[PurchaseOrder<br/>status=0 待审批]
    B --> C[管理员审批]
    C --> D{通过?}
    D -- 否 --> E[status=2 驳回]
    D -- 是 --> F[status=1 已审批]
    F --> G[到货入库<br/>批次 PharmaceuticalBatch]
    G --> H[录入批次号/有效期/数量]
    H --> I[库存 stock += 入库数]
    I --> J[台账 StockLedger 记录<br/>type=in]
    J --> K{库存低于阈值?}
    K -- 是 --> L[库存预警 stockAlert]
    K -- 否 --> M[✅ 入库完成]
    L --> M
```

## 6. 库存盘点与调整

```mermaid
flowchart TD
    A[定期盘点<br/>POST /pharmacy/stockCheck] --> B[录入各药品实盘数]
    B --> C{实盘数合法?<br/>非负整数/不重复}
    C -- 否 --> D[❌ 盘点明细格式错误]
    C -- 是 --> E[计算盈亏 = 实盘 - 账面]
    E --> F{有差异?}
    F -- 是 --> G[库存调整 inventoryAdjustment<br/>生成调整单]
    G --> H[按批次调整 stock]
    H --> I[台账 StockLedger<br/>type=adjust]
    F -- 否 --> J[✅ 账实相符]
    I --> J
```

## 7. 药品报损

```mermaid
flowchart TD
    A[发现破损/过期药品] --> B[提交报损申请<br/>POST /drugDamage/create]
    B --> C[填写批次+数量+原因]
    C --> D[管理员审批]
    D --> E{通过?}
    E -- 否 --> F[驳回]
    E -- 是 --> G[批次库存扣减]
    G --> H[台账 StockLedger type=damage]
    H --> I[✅ 报损完成 账实同步]
```

## 8. 特殊药品（麻精）双人管理

```mermaid
flowchart TD
    A[麻精药品处方] --> B[专用处方开立<br/>specialDrug 登记]
    B --> C[双人复核<br/>开方医生 + 药师]
    C --> D{双人确认?}
    D -- 否 --> E[❌ 拒绝发药]
    D -- 是 --> F[专用账册登记<br/>批号/数量/双人签字]
    F --> G[日结/月结专用报表]
    G --> H[✅ 追溯链完整]
```

## 9. 皮试流程

```mermaid
flowchart TD
    A[处方含需皮试药品] --> B[护士执行皮试<br/>POST /skinTest/create]
    B --> C[20分钟后读取结果]
    C --> D{结果?}
    D -- 阴性 --> E[skinTest.status=1<br/>可继续输液/发药]
    D -- 阳性 --> F[skinTest.status=2<br/>记录反应]
    F --> G[❌ 阻止该药使用<br/>通知医生换药]
    E --> H[✅ 继续治疗]
```
