# 住院与手术业务流程图

> 数据来源：`app/routers/admission.py`、`discharge.py`、`inpatient_order.py`、`surgery.py`、`inpatient_charge.py`、`ward.py`（2026-08 代码实况）

## 1. 入院登记

```mermaid
flowchart TD
    A[医生开入院证] --> B[护士办理入院<br/>POST /admission/create]
    B --> C{床位可用?<br/>status==0 且未禁用}
    C -- 否 --> D[❌ 床位不可用/已占用]
    C -- 是 --> E{该患者已有在院记录?}
    E -- 是 --> F[❌ 已有在院记录]
    E -- 否 --> G[生成入院号<br/>_generate_admission_no]
    G --> H[创建 Admission<br/>status=1 在院]
    H --> I[床位置 status=1 占用]
    I --> J{床位费单价>0?}
    J -- 是 --> K[生成床位费 InpatientCharge<br/>status=0 待结算]
    J -- 否 --> L[跳过]
    K --> M[✅ 入院成功]
    L --> M
```

**入院类型**：0 门诊入院 / 1 急诊入院 / 2 转诊入院 / 3 预约入院（`admission.py:50`）。

## 2. 住院医嘱全生命周期

```mermaid
flowchart TD
    A[医生开医嘱<br/>POST /inpatientOrder/create] --> B{患者在院?<br/>admission.status==1}
    B -- 否 --> C[❌ 患者不在院]
    B -- 是 --> D[创建 InpatientOrder<br/>status=0 新开]
    D --> E[生成执行计划<br/>_create_order_executions]
    E --> F{医嘱类型}
    F -- 临时医嘱 type=1 --> G[生成1条 OrderExecution<br/>status=0]
    F -- 长期医嘱 --> H[按频次 qd/bid/tid/qid<br/>×天数生成 N 条]
    G --> I[护士审核<br/>POST /inpatientOrder/audit]
    H --> I
    I --> J{status==0 且本人医嘱?}
    J -- 否 --> K[❌ 状态不正确/无权审核]
    J -- 是 --> L[原子置 status=1 已审核]
    L --> M[护士执行<br/>POST /inpatientOrder/execute]
    M --> N{order.status∈1,2<br/>且有 status=0 的执行记录?}
    N -- 否 --> O[❌ 不允许执行]
    N -- 是 --> P[原子更新执行记录<br/>status=1已执行/2已跳过<br/>记录 nurse_id+时间]
    P -- 行数≠1 --> Q[❌ 已被其他护士处理]
    P -- 行数=1 --> R{order.status==1?}
    R -- 是 --> S[order.status=2 执行中]
    R -- 否 --> T[保持执行中]
    S --> U[✅ 执行完成]
    T --> U
```

**医嘱状态机**：`0 新开 → 1 已审核 → 2 执行中 → 3 已停止`；`0/1 → 4 已撤销`（`inpatient_order.py:95`）。

```mermaid
stateDiagram-v2
    [*] --> 新开0: 医生开立
    新开0 --> 已审核1: 护士审核
    已审核1 --> 执行中2: 首次执行
    已审核1 --> 已停止3: 停止医嘱
    执行中2 --> 已停止3: 停止医嘱
    新开0 --> 已撤销4: 撤销
    已审核1 --> 已撤销4: 撤销
    已停止3 --> [*]
    已撤销4 --> [*]
```

**停止/撤销联动**：停止与撤销均将未执行（status=0）的执行计划批量置 3 已取消；撤销额外将关联费用记录标记退费（`inpatient_order.py:269-339`）。**出院自动停止**：办理出院时所有 0/1 状态医嘱自动置 3，防止出院后仍被检查执行（`discharge.py:44-53`）。

## 3. 出院结算

```mermaid
flowchart TD
    A[护士办理出院<br/>POST /discharge/doDischarge] --> B{admission.status==1 在院?}
    B -- 否 --> C[❌ 不在院状态无法办理]
    B -- 是 --> D[汇总费用<br/>SUM total_amount<br/>WHERE status!=2 已退费]
    D --> E[未结算费用 status=0<br/>批量置 status=1]
    E --> F[停止所有 0/1 状态医嘱]
    F --> G[admission.status=2 已出院<br/>记录出院时间/诊断]
    G --> H[床位释放 status=0]
    H --> I{已有出院小结?}
    I -- 否 --> J[自动创建 DischargeSummary<br/>住院天数=出院-入院+1]
    I -- 是 --> K[复用现有小结]
    J --> L[✅ 出院完成]
    K --> L
```

**费用口径**：出院时以 `status != 2`（排除已退费）汇总应收，未结费用自动转已结（`discharge.py:32-41`）。

## 4. 手术审批与排台

```mermaid
flowchart TD
    A[医生提交手术申请<br/>POST /surgeryApplication/create] --> B{入院记录存在?}
    B -- 否 --> C[❌ 入院记录不存在]
    B -- 是 --> D[SurgeryApplication<br/>status=0 待审批<br/>含手术级别/麻醉方式]
    D --> E[临床角色审批<br/>POST /surgeryApplication/approve]
    E --> F{status==0?}
    F -- 否 --> G[❌ 申请状态不正确]
    F -- 是 --> H[status=1 已批准<br/>记录审批人+时间]
    H --> I[排台 surgerySchedule/create<br/>status=0 待手术]
    I --> J[手术日<br/>status=1 手术中]
    J --> K[术后 status=2 已完成]
    K --> L[麻醉记录 anesthesiaRecord<br/>出血量/并发症]
    L --> M[✅ 手术闭环]
    D -- 取消 --> N[status=4 已取消<br/>联动排台 status=3]
```

**越权防护**：审批与列表均限临床角色（2026-08 安全修复，患者角色无法审批手术）。

## 5. 住院费用与预交金

```mermaid
flowchart TD
    A[预交金充值<br/>POST /prepaid/recharge] --> B[PrepaidTransaction<br/>type=recharge]
    B --> C[余额 balance_after 更新]
    C --> D[医嘱/护理计费<br/>InpatientCharge status=0]
    D --> E{费用发生时}
    E -- 预交金扣款 --> F[type=deduct<br/>条件更新余额]
    E -- 出院结算 --> G[未结费用批量置1]
    F --> H{余额不足?}
    H -- 是 --> I[催缴提醒]
    H -- 否 --> J[继续]
    I --> J
    G --> K[出院退余额<br/>type=refund]
    K --> L[✅ 资金闭环]
```

## 6. 病区床位管理

```mermaid
flowchart TD
    A[病区 Ward] --> B[床位 Bed status]
    B --> C[0 空闲]
    B --> D[1 占用]
    B --> E[2 禁用]
    C -- 入院 --> D
    D -- 出院 --> C
    C -- 维修 --> E
    E -- 恢复 --> C
    D -- 换床 --> C
```

**床位校验**：入院时校验床位 status=0 且未禁用（`admission.py:96-104`）；出院时释放（`discharge.py:60-63`）。
