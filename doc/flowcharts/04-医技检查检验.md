# 医技检查检验业务流程图

> 数据来源：`app/routers/lab.py`、`imaging.py`、`integration.py`、`exam.py`、`lab_qc.py`（2026-08 代码实况）

## 1. 检验全流程（申请→报告）

```mermaid
flowchart TD
    A[医生开检验申请<br/>LabOrder status=0<br/>sample_status=0] --> B[采样贴条码]
    B --> C[样本接收<br/>POST /lab/sampleReceive]
    C --> D{status==0 且<br/>sample_status==0?}
    D -- 否 --> E[❌ 不允许接收]
    D -- 是 --> F[sample_status=1 已接收<br/>记录流转日志]
    F --> G{样本合格?}
    G -- 不合格 --> H[拒收 sample/sampleReject<br/>sample_status=2<br/>需重新采样]
    H --> B
    G -- 合格 --> I[检验技师录入结果<br/>POST /labResult/create]
    I --> J{sample_status==1<br/>且无已录结果?}
    J -- 否 --> K[❌ 样本未接收/已录入]
    J -- 是 --> L[check_critical_value<br/>血压/血糖/心率危急值判定]
    L --> M[LabResult audit_status=0<br/>critical_status=1或0]
    M --> N[LabOrder.status=1 已出结果]
    N --> O[审核 POST /labResult/audit]
    O --> P{audit_status==0<br/>且 order.status==1?}
    P -- 否 --> Q[❌ 不允许审核]
    P -- 是 --> R[audit_status=1 已审核<br/>order.status=2 已完成]
    R --> S[✅ 报告发布]
```

## 2. 危急值闭环管理

```mermaid
flowchart TD
    A[录入结果时<br/>check_critical_value] --> B{达到危急值阈值?}
    B -- 是 --> C[critical_status=1<br/>返回警示消息]
    B -- 否 --> D[正常报告流程]
    C --> E[技师通知<br/>POST /labResult/critical/notify]
    E --> F{status==1?}
    F -- 已通知 --> G[幂等返回]
    F -- 是 --> H[critical_status=2<br/>站内信通知开单医生]
    H --> I[开单医生确认<br/>POST critical/acknowledge]
    I --> J{是开单医生或管理员?}
    J -- 否 --> K[❌ 403 只有开单医生可确认]
    J -- 是 --> L{status>=2 已通知?}
    L -- 否 --> M[❌ 尚未通知不能确认]
    L -- 是 --> N[critical_status=3 已确认]
    N --> O[医生处理<br/>POST critical/handle]
    O --> P{填写处理记录?}
    P -- 否 --> Q[❌ 必须填写处理记录]
    P -- 是 --> R[critical_status=4 已处理<br/>记录处理措施]
    R --> S[✅ 危急值闭环]
```

**状态链**：`0 非危急 → 1 待通知 → 2 已通知 → 3 已确认 → 4 已处理`，每步条件 UPDATE + 幂等返回（`lab.py:233-321`）。确认与处理仅限开单医生（或管理员）。

## 3. 影像检查（PACS 对接）

```mermaid
flowchart TD
    A[医生开影像申请<br/>POST /imaging/order/create] --> B[ImagingOrder status=0 待检查]
    B --> C[患者到影像科]
    C --> D[技师更新状态<br/>POST /imaging/order/status]
    D --> E[status=1 检查中]
    E --> F[拍片完成]
    F --> G{报告来源}
    G -- 本院录入 --> H[技师/医师保存报告<br/>POST /imaging/report/save]
    G -- PACS 回调 --> I[POST /integration/pacs/report<br/>集成密钥校验]
    I --> J{external_order_id<br/>幂等 + viewer_url<br/>https校验}
    J -- 重复回调 --> K[幂等返回]
    J -- 首次 --> L[写入报告+云胶片URL]
    H --> M[报告提交<br/>POST /imaging/report/submit]
    L --> M
    M --> N[status=0 待审核]
    N --> O[上级医师审核<br/>POST /imaging/report/review]
    O --> P{审核通过?}
    P -- 否 --> Q[驳回修改]
    Q --> H
    P -- 是 --> R[报告发布 status=1]
    R --> S[医生端查看<br/>云胶片 window.open viewer_url]
```

## 4. 检验质控（QC）

```mermaid
flowchart TD
    A[每日质控样本检测] --> B[录入质控数据<br/>POST /labQc/create]
    B --> C[计算均值/标准差<br/>Levey-Jennings 判定]
    C --> D{质控规则}
    D -- 在控 --> E[qc_status=0 在控<br/>可发布患者报告]
    D -- 警告 --> F[qc_status=1 警告]
    D -- 失控 --> G[qc_status=2 失控]
    F --> H[复查质控]
    G --> I[失控处理<br/>查找原因/重做质控]
    I --> J[填写纠正措施]
    J --> K[恢复在控]
    H --> K
    K --> E
```

## 5. 体检管理

```mermaid
flowchart TD
    A[体检登记] --> B[选择体检套餐<br/>examPackage]
    B --> C[生成体检记录<br/>examRecord status=0 待检]
    C --> D[分项目检查<br/>examItem 逐项录入]
    D --> E{全部项目完成?}
    E -- 否 --> D
    E -- 是 --> F[总检医生审核<br/>status=3 已完成]
    F --> G[生成体检报告<br/>examReport]
    G --> H[异常指标汇总]
    H --> I[✅ 报告发布]
```

**患者数据隔离**：examRecord/examReport/examResult 的列表与详情接口对 patient 角色强制过滤本人记录（2026-08 安全修复）。
