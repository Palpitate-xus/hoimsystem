# 病历文书业务流程图

> 数据来源：`app/routers/emr.py`、`medical_record_archive.py`、`medical_record_home.py`、`medical_record_home_quality.py`、`digital_signature.py`、`icd10.py`、`diagnosis_template.py`（2026-08 代码实况）

## 1. 结构化病历与签名

```mermaid
flowchart TD
    A[医生接诊] --> B[选择病历模板<br/>emrTemplate]
    B --> C[填写结构化病历<br/>POST /structuredMedicalRecord/create]
    C --> D[病历 status=0 草稿]
    D --> E[医生修改完善<br/>POST update 可反复]
    E --> F[医生签名<br/>POST /sign]
    F --> G{CA 证书校验}
    G -- 失败 --> H[❌ 签名失败]
    G -- 通过 --> I[记录签名时间/签名值<br/>病历锁定]
    I --> J{需要上级审签?}
    J -- 是 --> K[上级医师审签<br/>双签完成]
    J -- 否 --> L[✅ 病历生效]
    K --> L
```

## 2. 病程记录与查房

```mermaid
flowchart TD
    A[住院患者] --> B[首次病程记录<br/>progressNote/create<br/>入院8小时内]
    B --> C[日常病程记录<br/>按病情频次]
    C --> D[主任查房记录<br/>wardRound/create]
    D --> E{病情变化?}
    E -- 是 --> F[随时记录<br/>抢救记录6小时内补记]
    E -- 否 --> G[常规记录频次<br/>危重:每日/稳定:2-3日]
    F --> H[阶段小结]
    G --> H
    H --> I[出院前总结]
```

## 3. 病案首页与归档

```mermaid
flowchart TD
    A[患者出院] --> B[编码员填写病案首页<br/>medicalRecordHome]
    B --> C[ICD-10 诊断编码<br/>icd10 主诊断+其他诊断]
    C --> D[手术操作编码 ICD-9-CM]
    D --> E[首页质控校验<br/>medicalRecordHomeQuality]
    E --> F{质检通过?}
    F -- 否 --> G[退回修改<br/>标注缺陷项]
    G --> B
    F -- 是 --> H[提交病案室]
    H --> I[病案归档<br/>medicalRecordArchive/create]
    I --> J{出院2日内?}
    J -- 是 --> K[按时归档]
    J -- 否 --> L[逾期归档标记<br/>纳入质控考核]
    K --> M[归档后只读<br/>修改需申请解锁]
    L --> M
    M --> N[✅ 归档完成]
```

## 4. 病案借阅

```mermaid
flowchart TD
    A[临床/科研需调阅病案] --> B[提交借阅申请<br/>archive 相关接口]
    B --> C[填写借阅理由/期限]
    C --> D[病案室审批]
    D --> E{批准?}
    E -- 否 --> F[❌ 驳回]
    E -- 是 --> G[授权在线调阅<br/>限定时限]
    G --> H[到期自动收回权限]
    H --> I[✅ 借阅闭环]
```

## 5. 电子签名（CA）

```mermaid
flowchart TD
    A[医生注册 CA 证书<br/>digitalSignature/create] --> B[绑定 user_id<br/>证书指纹存储]
    B --> C[签名时使用]
    C --> D[POST /structuredMedicalRecord/sign 等]
    D --> E[后端校验证书有效性]
    E --> F[对文书内容计算摘要]
    F --> G[生成签名值<br/>记录签名时间]
    G --> H[文书与签名绑定存储]
    H --> I[✅ 抗抵赖]
    I --> J[事后验证可验签]
```

## 6. 诊断模板

```mermaid
flowchart TD
    A[医生维护个人/科室模板<br/>diagnosisTemplate/create] --> B[模板内容: 主诉/现病史/<br/>诊断/用药建议]
    B --> C[开病历时选择模板]
    C --> D[基于模板快速生成<br/>再个体化修改]
    D --> E[✅ 提升文书效率]
```
