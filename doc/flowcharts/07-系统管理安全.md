# 系统管理与安全业务流程图

> 数据来源：`app/routers/user.py`、`admin.py`、`system.py`、`monitor.py`、`backup.py`、`data_import_export.py`、`research.py`、`report.py`（2026-08 代码实况）

## 1. 用户认证（登录/注册）

```mermaid
flowchart TD
    A[用户访问登录页] --> B[输入用户名/密码<br/>前端 RSA 公钥加密]
    B --> C[POST /api/login]
    C --> D{锁定检查<br/>LoginLockout 表}
    D -- 5次失败/5分钟 --> E[❌ 429 登录失败次数过多]
    D -- 未锁定 --> F[RSA 解密传输密码]
    F --> G{bcrypt 校验通过?}
    G -- 否 --> H[记录失败到数据库<br/>fail_count+1]
    H --> D
    G -- 是 --> I[清除锁定计数]
    I --> J{遗留明文哈希?}
    J -- 是 --> K[自动升级为 bcrypt]
    J -- 否 --> L[签发 JWT<br/>含 sub/exp/iat 24h]
    K --> L
    L --> M[✅ 返回 accesstoken]
    M --> N[后续请求 Header accesstoken]
    N --> O[get_current_user 校验]
    O --> P{exp 有效 且<br/>iat >= token_invalid_before?}
    P -- 否 --> Q[❌ 401 已吊销/过期]
    P -- 是 --> R[✅ 通过]
```

**注册**：患者自助注册统一返回模糊提示（防账号枚举）；首次注册自动创建 Patient 档案。

## 2. 登出与 Token 吊销

```mermaid
flowchart TD
    A[POST /api/logout] --> B[用户 token_invalid_before=now]
    B --> C[该用户此前签发的<br/>全部 JWT 立即失效]
    C --> D[✅ 服务端可撤销]
    E[管理员重置密码] --> F[token_invalid_before=now]
    F --> C
```

## 3. 登录失败锁定（跨 worker）

```mermaid
flowchart TD
    A[登录失败] --> B[LoginLockout 表<br/>lock_key=IP:用户名]
    B --> C[fail_count+1]
    C --> D{累计>=5?}
    D -- 是 --> E[locked_until=now+5min<br/>计数清零]
    D -- 否 --> F[等待下次尝试]
    E --> G[锁定期内全部拒绝 429]
    G --> H[期满自动解锁]
    F --> I[登录成功时清除记录]
    H --> I
```

## 5. 数据备份恢复

```mermaid
flowchart TD
    A[管理员发起备份<br/>POST /backup/create] --> B{生产 PostgreSQL?}
    B -- 是 --> C[❌ 501 需使用 PG 备份工具]
    B -- 否 SQLite --> D[复制 .db 到 backups/]
    D --> E[✅ 备份完成]
    F[恢复 POST /backup/restore] --> G{文件名校验}
    G -- 含路径/非.db --> H[❌ 拒绝]
    G -- 合法 --> I[shutil.copy2 覆盖]
    I --> J[✅ 恢复完成 需重启]
    K[下载 GET /backup/download] --> G
```

## 7. 数据导入（Excel 批量）

```mermaid
flowchart TD
    A[管理员上传 xlsx<br/>POST /dataImportExport/import] --> B[openpyxl data_only=True<br/>读取缓存值 防公式注入]
    B --> C[逐行解析校验]
    C --> D{行数据合法?}
    D -- 否 --> E[跳过并记录错误行]
    D -- 是 --> F{已存在同名记录?}
    F -- 是 --> G[更新]
    F -- 否 --> H[新建]
    H --> I{患者行?}

    I -- 否 --> K[直接入库]
    J --> K
    G --> L[汇总导入结果]
    K --> L
    E --> L
```

## 10. 定时任务（scheduler.py）

```mermaid
flowchart TD
    A[scheduler_loop<br/>每小时] --> B{遍历 JOB_NAMES}
    B --> C[inventory_alert<br/>低库存计数]
    B --> D[breach_statistics<br/>24h 违约统计]
    B --> E[breach_scan<br/>违约扫描]
    B --> F[backup<br/>登记状态 实际由 API 执行]
    E --> E1[扫描前一日<br/>status=0 未报到预约]
    E1 --> E2{已有违约记录?<br/>幂等}
    E2 -- 否 --> E3[记 BreachRecord<br/>超时未报到]
    E3 --> E4[预约置 status=2 取消]
    E4 --> E5[排班 number+1<br/>回补号源]
    E2 -- 是 --> E6[跳过]
    C & D & E & F --> G[更新 _state<br/>status 接口可查]
```

> 手动触发：`POST /scheduler/run`（admin）；状态查询：`GET /scheduler/status`。单任务失败不影响其他任务与主服务。
