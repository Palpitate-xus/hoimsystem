# 患者服务业务流程图

> 数据来源：`app/routers/patient.py`、`family_member.py`、`patient_card.py`、`referral.py`、`mdt.py`、`charge.py`（prepaid/payment）、`triage_desk.py`（2026-08 代码实况）

## 1. 患者注册

```mermaid
flowchart TD
    A[自助注册页] --> B[填写姓名/身份证号<br/>手机号/密码 RSA 加密]
    B --> C[POST /api/register]
    C --> D{密码 6-20 位?}
    D -- 否 --> E[❌ 密码长度必须为6至20位]
    D -- 是 --> F{身份证号已注册<br/>Patient 或 User?}
    F -- 是 --> G[❌ 模糊提示: 注册失败<br/>防账号枚举]
    F -- 否 --> H[创建 Patient 档案<br/>permission=allow]
    H --> I[创建 User 账号<br/>username=身份证号<br/>role=patient / bcrypt]
    I --> J[✅ 注册成功 可登录]
```

## 2. 家庭成员代办

```mermaid
flowchart TD
    A[登录患者账号] --> B[添加家庭成员<br/>POST /familyMember/create]
    B --> C{被添加人身份证号}
    C --> D{对方是已注册患者<br/>且 permission=allow?}
    D -- 是 --> E[❌ 拒绝绑定<br/>防身份证号劫持 PHI]
    D -- 否 --> F[创建 FamilyMember 关联]
    F --> G[代办人可为其<br/>预约/缴费/查报告]
    G --> H[本人后续注册时<br/>可接管档案]
```

**劫持防护**：2026-08 安全修复——已注册且授权（permission=allow）的患者档案禁止被他人以家庭成员方式绑定。

## 3. 智能导诊与院内导航

```mermaid
flowchart TD
    A[患者描述症状] --> B[智能导诊 triage<br/>推荐就诊科室]
    B --> C[患者选择科室]

```

## 4. 就诊卡管理

```mermaid
flowchart TD
    A[窗口办卡<br/>POST /patientCard/create] --> B[关联身份证号<br/>生成卡号]
    B --> C[预交金充值<br/>POST /prepaid/recharge]
    C --> D[余额入账<br/>PrepaidTransaction 记录]
    D --> E[就诊消费<br/>条件扣减余额]
    E --> F{余额不足?}
    F -- 是 --> G[充值提醒]
    F -- 否 --> H[继续就诊]
    G --> H
    H --> I[退卡<br/>余额退还]
```

## 5. 线上支付

```mermaid
flowchart TD
    A[患者查看待缴费用] --> B[发起支付<br/>POST /payment/create]
    B --> C[Payment status=0 待支付<br/>关联 charge_id]
    C --> D{支付渠道}
    D -- 微信/支付宝 --> E[唤起支付]
    E --> F[支付回调<br/>POST /integration/payment/notify]
    F --> G{集成密钥校验<br/>+ 幂等}
    G -- 通过 --> H[Payment status=1 已支付<br/>Charge status=1 已缴费]
    G -- 重复回调 --> I[幂等返回]
    D -- 窗口缴费 --> J[chargeManagement/charge]
    H --> K[✅ 缴费完成]
    J --> K
    E -- 超时未付 --> L[status=2 失效<br/>可重新发起]
```

## 6. 双向转诊

```mermaid
flowchart TD
    A[基层医院/本院医生<br/>发起转诊 referral/create] --> B[转诊单 status=0<br/>含病历摘要]
    B --> C{转诊方向}
    C -- 转入 --> D[本院接收]
    C -- 转出 --> E[上级医院]
    D --> F[主任/管理员审批<br/>referralApproval]
    E --> F
    F --> G{批准?}
    G -- 否 --> H[❌ 驳回 补充材料]
    G -- 是 --> I[status=1 已批准]
    I --> J[患者持转诊单就诊<br/>优先安排]
    J --> K[诊疗完成回填<br/>反馈基层医院]
    K --> L[✅ 转诊闭环]
```

## 7. 多学科会诊（MDT）

```mermaid
flowchart TD
    A[疑难病例] --> B[主管医生发起 MDT<br/>POST /mdt/create]
    B --> C[填写会诊目的<br/>拟定参与科室]
    C --> D[邀请多科专家<br/>status=0 待确认]
    D --> E[各科专家确认参与]
    E --> F{全部确认?}
    F -- 否 --> G[调整时间/人选]
    G --> D
    F -- 是 --> H[确定会诊时间<br/>status=1 已排期]
    H --> I[会诊执行<br/>多学科讨论]
    I --> J[形成综合诊疗方案<br/>记录会诊意见]
    J --> K[✅ MDT 闭环]
```
