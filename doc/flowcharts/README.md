## 图例约定

- 流程图中的 `status=N` 均为数据库实际存储的整型状态值，与 `doc/data-dictionary.md` 枚举对应
- `原子置/原子扣减` 表示条件 UPDATE + rowcount 校验的并发安全写法（本系统资金/库存/状态流转统一采用）
- `❌` 表示业务拒绝路径，`✅` 表示成功终点
- 代码位置引用格式：`文件:行号`
