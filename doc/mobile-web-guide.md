# 移动 Web 使用说明

前端生产构建包含 Web App Manifest 和 Service Worker，可在支持 PWA 的手机浏览器中添加到主屏幕。现有患者端页面沿用响应式布局，适合先作为移动 Web 入口使用。

## 安装与缓存边界

打开生产站点后，使用浏览器的“添加到主屏幕/安装应用”操作。Service Worker 只缓存同源静态资源，不缓存 `/api/` 请求、患者数据或医疗动态内容；登出、权限变化和后端发布后的静态资源以网络响应为准。

## 现阶段边界

该能力不是原生 App 或微信小程序。若要发布原生端/小程序，需要进一步确定端侧功能范围、推送渠道、设备权限、隐私协议、应用商店/小程序主体和独立验收计划。
