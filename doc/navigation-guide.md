# 院内导航配置指南

系统提供可配置的院内路线图，不依赖外部地图服务即可返回科室之间的最短路线。

## 配置顺序

1. 管理员进入“院内路线管理”，创建入口、途经点和科室节点。
2. 科室节点关联院区和科室；同一院区的节点才能建立路线。
3. 在“路线连线”中填写起点、终点、距离和现场指引；单向通道关闭“双向”。
4. 在患者端“就诊导航”选择起点和终点，系统返回总距离及逐段指引。

节点被路线使用时不能直接删除，需先删除相关连线；停用节点或连线不会参与路线计算。未配置完整路线时，患者端会提示联系导诊台并要求以现场标识为准。

实时地图、室内定位、无障碍路径和动态封路属于外部地图/物联网能力，仍需医院地图数据和厂商服务联调。
