# 等保本地安全基线自评清单

本清单用于整理代码和开发环境中已经具备的证据，不能替代具有资质机构的等保测评、渗透测试或医院信息安全管理制度评审。

## 已有代码证据

| 控制域 | 本地证据 | 状态 |
|---|---|:---:|
| 身份鉴别 | JWT 登录态、bcrypt 密码存储、RSA 传输密码、登录失败限流 | ✅ |
| 访问控制 | 路由角色依赖、角色矩阵测试、患者数据范围限制 | ✅ |
| 安全审计 | 操作日志记录用户、角色、路径、结果、IP 和响应耗时 | ✅ |
| 入侵防范 | Pydantic 输入校验、ORM 参数绑定、XSS 清理、Origin 校验 | ✅ |
| 数据保护 | 身份证/手机号按角色脱敏，敏感 GET 纳入审计 | ✅ |
| 备份恢复 | 管理员备份/恢复接口、部署与备份文档 | ✅ |
| 外部接口 | LIS/PACS/医保专用密钥、失败码、外部单号绑定、幂等回调 | ✅ |
| 配置安全 | 生产环境强制 SECRET_KEY，遗留配置备份不再保存凭据 | ✅ |

## 测评前必须补齐的运营证据

- [ ] 等保定级、备案和测评机构确认。
- [ ] 生产环境 HTTPS/TLS 证书、网关白名单和数据库网络隔离截图/配置留档。
- [ ] 账号生命周期、最小权限、离职回收和定期复核记录。
- [ ] 备份异地保存、恢复演练、RPO/RTO 和介质销毁记录。
- [ ] 主机、容器、数据库和依赖包的漏洞扫描报告及整改闭环。
- [ ] 日志集中存储、留存周期、告警值班和时间同步记录。
- [ ] 医疗数据分级、脱敏导出审批、第三方接口密钥轮换记录。
- [ ] 渗透测试、弱口令检查、应急预案演练和测评报告。

## 结论

系统已完成可在代码仓库内验证的安全控制与证据整理；“等保合规检查”仍保持待办，原因是其完成条件包含医院组织、生产环境和第三方测评证据，不能仅通过本地单元测试宣称完成。
