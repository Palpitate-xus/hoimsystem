# 2026-10-29 图标与导航修复

检查全部359个Vue单文件组件，并用生产包复现缺失现象。原有293个SVG的图形数据完整，问题出在名称转换、组件绑定和样式。

## 原因和修改

| 原因 | 修改 |
| --- | --- |
| 旧转换表只认识部分FontAwesome别名，原预览15个父菜单中14个回退为省略号 | 统一名称解析，支持PascalCase、连字符名称及旧数组配置；菜单和页签使用同一解析结果 |
| 首页4个图标和折叠箭头被输出为空的自定义HTML标签 | 动态选择绑定已导入的组件对象 |
| 患者导航、导诊漏导入4个图标；3处操作属性传入未注册的组件名 | 补齐导入，将按钮和输入框属性绑定为组件对象 |
| 兼容组件通过`h("el-icon")`生成原生标签 | 改为实际的`ElIcon`组件 |
| 导航样式对SVG叠加尺寸、内边距和间距 | 按钮32px、内部图标20px；横向布局使用清楚的浅色图标 |
| 登录页CSS从`css/static/`请求背景图，实际文件位于`static/` | 配置提取CSS所引用资源的相对路径，并新增登录资源回归 |

144个有标题的路由全部配置图标，17个顶层入口使用不同图标。实际超级管理员权限可见16个入口；患者服务按既有权限显示。子页面按患者、处方、排班、库存、费用、设备等业务选择图标。

图标继续使用现有依赖和SVG资源。全屏按钮进入和退出时显示不同图标，并在组件卸载时清理监听。顶部按钮提供键盘操作和可访问名称。
