## 已验证的行为

- 401、403、404、400、402、413、422、限流、服务故障、未完成、模型拒绝及格式问题分别给出处理建议；现有领域错误码保持兼容。
- 临时 HTTP 与连接建立失败按 1–3 次配置执行。随机退避保留 Retry-After 下限；超出剩余时间或等待上限时停止。请求发送、读取及关闭失败不触发重放，读取与关闭共用原总时限。
- 每次重发重新核对任务租约、取消状态、权限、来源和配置。测试覆盖撤权及配置改变后停止后续请求。
- 用量缺失、部分已知、明确为零、重复 JSON 字段、非有限数值、异常结构与过深解析分别处理；错误消息和日志不带原 Prompt、响应正文或凭据。
- 普通结果事务失败先回滚，再以原任务及租约通过独立 Session 记录失败和实际用量；已取消或已完成任务及其他租约不会被覆盖。数据库持续失败由过期恢复继续处理。
- 页面查询暂停可以恢复读取原任务；已知创建回执和未知提交回执分别处理，相同未知提交在当前页面中暂停重发。后端具体指导优先于通用前端提示，应用登录失效和权限错误单独处理。
